
# React Course Cards

A responsive React application that displays programming courses with images, descriptions, and prices.

## Features

- Displays multiple programming courses in a card layout.
- Includes course images, names, descriptions, and prices.
- Responsive layout for different screen sizes.
- Reusable React components.
- Clean and simple user interface.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/k-siddhartha-ai/react-course-cards.git
   ```

2. Open the project folder:

   ```bash
   cd react-course-cards
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Build for Production

```bash
npm run build
```

The production files will be generated in the `dist` folder.

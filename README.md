# 🚀 React Course Cards | Interactive Programming Courses UI

A clean, responsive React.js application that showcases programming courses through visually appealing course cards. Each card displays a course image, title, description, and price.

Built to practice component-based development, reusable React components, props, conditional rendering, and modern frontend development.

## 📌 Project Overview

React Course Cards is a frontend application designed to present programming courses in an organized card-based layout.

The application uses reusable React components to display course information dynamically through props, making the interface easier to maintain and extend.

**The goal:** Build a simple, structured, and user-friendly course listing interface while strengthening practical React development skills.

## ✨ Key Features

- 📚 **Course Listing:** Displays 8 programming courses in an organized layout.
- 🖼️ **Course Images:** Each course has its own image.
- 💰 **Course Pricing:** Displays course prices.
- ♻️ **Reusable Components:** Uses a reusable `Course` component.
- ⚛️ **Props-Based Rendering:** Passes course information from the parent component to child components.
- 🎨 **Clean UI:** Simple and visually organized card design.
- 📱 **Responsive Layout:** Designed to adapt to different screen sizes.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/k-siddhartha-ai/react-course-cards.git
```

### 2. Navigate to the Project Directory

```bash
cd react-course-cards
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Your Browser

Open the local development URL displayed in your terminal (usually `http://localhost:5173`).

## 🏗️ Production Build

To create an optimized production build:

```bash
npm run build
```

The generated production files will be available in the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```
